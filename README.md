# 叙事账本 · Story Ledger

给 SillyTavern 用的**状态账本**扩展。

它不管文风，也不管记忆检索。它只管一件模型最容易写错的事：**现在是什么时候、在哪、谁在场、对她到什么程度、这件事归谁办、这间屋里有什么。**

配合长篇叙事卡使用，尤其适合「大世界 + 多角色 + 讲究礼法」的设定。

## 仓库里有什么

| 目录 | 内容 |
|---|---|
| `index.js` `src/` | 插件本体 |
| `packs/beiliang.worldpack.json` | **配套世界包**（历法、气候、礼法、人物、事件图、器物） |
| `packs/guofeng.worldpack.json` | 通用古风示例包，换卡时照它抄字段 |
| `worldbook/beiliang-v3.json` | 配套世界书 v3（70 条，已按插件改造） |
| `card/beiliang-card.json` | 配套角色卡（**内嵌世界书已剥离**） |
| `presets/GrayWill-0.45.2-账本版.json` | 配套预设（灰魂改版，见 `THIRD_PARTY.md`） |
| `DESIGN.md` | 完整设计书（18 个数据小节 + 实现总表） |

### 三位一体的用法

```
角色卡  +  世界书 v3  +  世界包
  ↑           ↑            ↑
叙事      设定与文风    可计算的状态
```

**世界书里不要再写好感、时间、位份**——那些由插件的 `[状态]` 块提供。
三者缺一个，状态块就是空的。

## 它能做什么

| 它管 | 具体 |
|---|---|
| **时间** | 古风历法（年号 / 月日 / 时辰刻），生成后按权威值重写首行时间头 |
| **地理** | 地点树、祖先链、邻接，越界标红 |
| **气候** | 季节 × 气候带 → 当天天气，同一天稳定，重生成不变天 |
| **在场** | 谁在、各自好感与档位、该怎么称呼 |
| **名分** | 位份、公开尺度、能否留宿、事后待遇 |
| **动机** | 她此刻为什么答应（屈从 / 交易 / 还恩 / 义务 / 情愿） |
| **礼法** | 礼、家法、国法：先按场景过滤候选，再判命中，给出后果 |
| **器物** | 原型 → 实例（按闲置年数定新旧）、物品四元组、归还规则、需求与缺口 |
| **事件** | 预置事件图（软/硬前置）+ AI 现编的自生事件 |
| **经验** | 与谁、第几次，决定「怎么做」 |

## 它不是什么

- **不做**向量检索、不做长文摘要 → 那是 [LittleWhiteBox](https://github.com/RT15548/LittleWhiteBox) 的活，两者并置使用
- **不做**地图渲染、不做绘图/语音
- **不会替模型写正文**——只往 prompt 里塞一小块状态

## 安装

1. 放进 `SillyTavern/public/scripts/extensions/third-party/st-narrative-ledger/`
2. 刷新页面 → 魔杖菜单出现「叙事账本」
3. 或者直接：ST → 扩展 → 安装扩展 → 粘
   `https://github.com/stasrsda/st-narrative-ledger`

## 第一次用

**1. 选世界包**

仓库自带 `packs/guofeng.worldpack.json`（通用古风示例）。想用自己的设定：

- 把私人的 `packs/beiliang.worldpack.json` 放进 `packs/`（已在 `.gitignore` 里，不会被提交）
- 或改用你自己的包，字段照 `guofeng` 那份抄

**2. 配副模型（可选）**

面板 → 世界包 → 填 ST 里已有的连接配置名（例如 `北凉·记账`）。

留空也能跑：状态块照常注入，但好感、礼法、自生事件不会自己变。

**3. 重置到开局**

面板 → 世界包 →「重置到开局」。

## 注入长什么样

```
[状态·只读·勿复述]
时:承平二十七年九月十四·酉初三刻 | 地:北凉城>雁回县>北门外五里
天:风沙 · 秋
在场:霍振(60/心腹/称"王爷")
事件:未结：地牢认字、查布防图、五营换防｜已结：雁回城破
与<info>冲突时以本块为准。
```

约 90 token。全部关掉时为零。

## 设计原则

1. **贵模型只读不写账本**：记账、验算、判定都在便宜通道或代码里
2. **决定论优先**：同一时刻、同一种子，天气/器物/好感折叠结果永远一致
3. **永不阻断**：任何失败都静默降级，让游戏继续
4. **可撤销**：状态是事件流折叠出来的，滑动/删楼自动回滚
